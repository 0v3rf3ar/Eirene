# Eirene 0.1.17

This stable release adds session and plugin browsers, improves provider
communication and performance, and hardens file edits and standalone builds.

- Browse the mother session and its subagents in an interactive popup tree.
  Open saved conversations and return to the mother session with M.
- Install predefined plugins, including Ponytail, and manage installed bundles
  through the floating `/plugins` catalog.
- Reuse provider HTTP connections, coordinate rate limits between agents, and
  validate conversation structure before sending inference requests.
- Preserve Gemini thought signatures, Anthropic thinking blocks, and
  DeepSeek/Kimi reasoning through tool loops and saved sessions. Handle stream
  completion, token limits, images, model pagination, and usage more accurately.
- Index session metadata and parent relationships for faster browsing while
  retaining JSONL logs as the source of truth.
- Protect file creation, rewrites, and exact-text edits with atomic replacement,
  preview checks, concurrent-change detection, and useful failure diagnostics.
- Reduce local-model instruction and schema overhead while preserving tool
  argument contracts.
- Build and validate standalone executables in staging before publication.
  Preserve the running process's original archive so replacing the executable
  does not break lazy imports when pressing Esc or opening a popup.
- Expand provider, workflow, popup, file-edit, and frozen-binary regression
  coverage, including real packaged UI smoke tests.

Release tag: `v0.1.17`. This is a stable release, available through `/update`.
