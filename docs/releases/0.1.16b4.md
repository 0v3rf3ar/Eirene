# Eirene 0.1.16b4

This beta fixes Windows emoji presentation and companion rendering.

- Manual-mode, auto-mode, and web-tool icons consistently request emoji
  presentation on Windows. Rich now requires version 14.3.3 or newer so emoji
  widths are measured correctly.
- The Sixel companion uses transparent pixels instead of painting a black
  rectangle around the character.
- Typing outside the companion's area leaves its pixels untouched. Pose
  changes keep the same widget mounted, and text updates and companion drawing
  share a synchronized update in Windows Terminal to reduce flickering.
- Companion rendering checks cover transparency, typing, blinking, resizing,
  and disabling the companion. Live Windows visual verification remains pending.

Release tag: `v0.1.16b4`. This is a prerelease and does not replace the latest
stable release. Install it using `/update edge`.
