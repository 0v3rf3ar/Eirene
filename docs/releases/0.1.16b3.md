# Eirene 0.1.16b3

This beta adds an explicit edge update channel.

- `/update` and `/update check` select stable releases only.
- `/update edge` includes alpha, beta, and release candidate versions, selecting
  the highest published version newer than the installed version.
- `/update edge check` checks that channel without downloading or installing.
- Startup update checks remain stable. Both channels retain download URL checks,
  checksum verification, and executable smoke tests.
- Side questions retain Eirene's identity even with an empty conversation.
- Web search and fetch tool cards use a globe icon, and the manual mode icon
  requests emoji presentation on Windows.

Release tag: `v0.1.16b3`. This is a prerelease and does not replace the latest
stable release.
