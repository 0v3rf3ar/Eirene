# Eirene 0.1.18

This stable release adds guided MCP setup and remote server connections,
improves provider compatibility, and refines the terminal interface.

- Add `/mcp add` and guided imports for MCP JSON and configuration files.
  Review connections, resolve missing settings, test servers, and enable them
  together or save them disabled.
- Support local stdio servers, Streamable HTTP, and legacy SSE connections.
  Add browser OAuth sign-in, bearer tokens, custom headers, and token refresh.
  Store remote credentials separately from the main configuration.
- Share remote MCP connections with native Codex and Claude Code providers
  through Eirene's bundled proxy. Prepare persistent server homes and caches,
  and show network and filesystem grants during setup.
- Include sourced MCP configuration examples for browser tools, databases,
  collaboration services, and development integrations.
- Improve DeepSeek thinking controls, model capabilities, image handling, and
  tool calls. Preserve signed provider history across tools, resume, import,
  and compaction, and keep runtime observations distinct from model messages.
- Avoid duplicate background process polling, preserve completed command
  results, improve Gemini quota recovery, and handle streamed completion more
  accurately.
- Give `/btw` context from the active task, plans, previous work, and current
  progress. Prevent overlapping side answers from mixing in the popup.
- Improve provider names, tool-output disclosure, permission details, and
  workspace trust presentation.

Release tag: `v0.1.18`. This is a stable release, available through `/update`.
