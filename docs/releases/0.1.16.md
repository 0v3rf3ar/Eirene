# Eirene 0.1.16

This stable release brings together the 0.1.16 beta improvements, with better
provider setup, terminal rendering, workspace trust, and installation.

- Add an optional animated companion, disabled by default. Use `/companion` in
  supported image terminals to toggle it; improve transparent rendering and
  reduce flickering in Windows Terminal.
- Separate stable and Edge updates. `/update` selects stable releases;
  `/update edge` includes prereleases. Improve Windows updating and add Edge
  options to the Bash and PowerShell installers.
- Improve ChatGPT sign-in browser launching and provider configuration status.
  Handle raw SSL failures through normal error paths and retry eligible TLS
  failures before a response or tool activity starts.
- Improve Windows emoji sizing, Markdown links, workspace trust presentation,
  and task display. Selecting input or transcript text copies it automatically
  and displays a brief character-count notification; masked API keys are excluded.
- Move default application data to `~/.local/share/eirene`. Migrate the previous
  `~/.local/eirene` directory when the new location does not exist; preserve
  explicit `EIRENE_HOME` settings and avoid merging existing directories.
- Refine installer progress, platform checks, and download handling.

The Raspberry Pi `SSL: BAD_VALUE` issue has not been reproduced on ARM64
hardware; this release improves recovery without claiming an underlying fix.

Install or upgrade through the standard installers, or run `/update` in Eirene.

**Full changelog:** https://github.com/0v3rf3ar/Eirene/compare/v0.1.15...v0.1.16
