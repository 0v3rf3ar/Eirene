# Eirene 0.1.16b2

This beta adds the optional graphical Eirene companion and returns prompt
editing to Textual's standard rendering and cursor behavior.

- `/companion [on|off]` silently toggles the companion and saves the preference.
  She starts disabled, including after upgrading from the earlier automatic
  default. The command is listed only in terminals supporting images.
- Thinking and work use the laptop pose; questions and approvals use the
  question pose. Idle blinking stays the same size, with her feet anchored to
  the input border. The picture overlays the interface without shifting it.
- Kitty uses a transparent native graphics placement. Clicking the character
  briefly makes her angry; repeated clicks make her furious. Reactions last
  one second and 1.3 seconds respectively.
- Compact PNG artwork preserves transparency and project attribution. Bundled
  companion frames total approximately 25 KB.
- Removed custom Persian/Arabic shaping and bidirectional input support,
  including the `arabic-reshaper` and `python-bidi` dependencies.

Release tag: `v0.1.16b2`. This is a prerelease and does not replace the latest
stable release.

Validation includes native Linux binary/archive smoke checks, package contents,
and companion/approval/question tests. Existing full-suite failures involving
provider prompts and context/output budgets also reproduce on beta1 and remain
outside this release's changes.
