# Eirene 0.1.17b1

This beta simplifies file editing and protects existing files when an edit fails.

- Remove Eirene's `apply_patch` tool and use exact-text `edit_file` modifications
  with the existing edit UI. Keep `write_file` for creation and full rewrites.
- Prepare and flush edits in a temporary sibling file before replacing the
  original. Report disk space, quota, permission, read-only filesystem, and I/O
  errors with recovery guidance. Detect concurrent changes before replacement.
- Preserve line endings, file modes, ownership, and supported extended attributes.
  Reject ambiguous matches, invalid text, and hard-linked files safely.
- Keep editing instructions concise while supporting large changes and complete
  rewrites. Route native Codex file-change approvals through the edit naming.
- Refine the trust-screen watermark and organize README beta installation
  commands into a collapsible section with platform labels.

Release tag: `v0.1.17b1`. This is a prerelease and does not replace the latest
stable release. Install it using `/update edge`.
