# Eirene 0.1.16b5

This beta improves ChatGPT connection error handling following repeated
`SSL: BAD_VALUE` failures reported on ARM64 Raspberry Pi Linux.

- Raw Python SSL errors during inference, model discovery, and authorization
  now use the existing handled-error paths instead of an unexpected failure.
- `SSL: BAD_VALUE` is recognized by the bounded TLS retry logic. Requests can
  retry before answer text or tool activity starts; interrupted answers and
  tool work are not automatically replayed.
- Regression tests cover raw and HTTPX-wrapped SSL failures, retry limits,
  preservation of partial output, and credentials after failed token refresh.

The underlying Raspberry Pi SSL failure has not been reproduced on ARM64
hardware; this release improves handling and recovery rather than claiming
to resolve its underlying cause.

Release tag: `v0.1.16b5`. This is a prerelease and does not replace the latest
stable release. Install it using `/update edge`.
