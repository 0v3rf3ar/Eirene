# Eirene 0.1.19

This stable release fixes shell startup failures in standalone binaries,
improves command and file-change displays, and updates native release builds.

- Restore the host library search path before launching external programs from
  the standalone binary. Avoid bundled Readline conflicts that could stop Bash
  and sh before a command or build started. Apply the same cleanup to provider
  CLIs, MCP servers, browser tools, language diagnostics, Git plugin installs,
  desktop helpers, scheduler commands, and update checks.
- Update original command cards when background commands finish, including
  automatic completions and results restored from saved sessions. Show success
  or failure instead of leaving completed commands yellow.
- Hide internal `read_output` calls from live chat, resumed transcripts, and
  headless activity output while keeping their results available to the model.
- Remove command-label underlines, use consistent bullet markers for commands
  and file changes, and indent command output and file-change summaries.
- Add `--continue` to reopen the latest workspace session without a picker.
- Show complete commands when expanded and trim them when collapsed. Simplify
  thinking and command status displays.
- Keep streaming answers pinned to the bottom when rendering falls behind
  incoming chunks, while preserving manual scrolling.
- Manage dependencies with uv and `uv.lock`, build native binaries with Python
  3.14, and require tests, lint, and type checks before release builds.
- Publish checked-in release notes with the complete native binary set and
  checksum manifest.

Release tag: `v0.1.19`. This is a stable release, available through `/update`.
