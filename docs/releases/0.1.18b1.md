# Eirene 0.1.18b1

This beta improves provider compatibility and makes side questions aware of the
session's task and progress.

- Add dedicated DeepSeek handling for thinking mode, reasoning replay, model
  capabilities, images, and tool calls.
- Keep runtime observations distinct from model messages across API providers,
  preserving reasoning and signatures through resume, import, and compaction.
- Avoid duplicate background process polling and preserve completed command
  results in the session and interface.
- Handle Gemini quota exhaustion and retry timing, and avoid marking complete
  output as partial merely because it ends with whitespace.
- Give `/btw` bounded context from user requests, plans, compaction handoffs,
  tool results, pending work, and streaming activity. Prevent overlapping side
  answers from mixing in the popup.

Release tag: `v0.1.18b1`. This is a prerelease.
