# Eirene 0.1.19b1

This beta updates dependency management and release builds, and refines the
command and status displays.

- Add `--continue` to reopen the latest workspace session without a picker.
- Show complete commands when expanded and trim them when collapsed.
- Make command status dots bolder, remove alternate thinking animations, and
  remove the redundant thinking-duration display.
- Manage runtime, development, and build dependencies with uv and `uv.lock`.
- Build all native release binaries with Python 3.14.
- Use Node 24 GitHub Actions and require tests, lint, and type checks before builds.
- Install Bubblewrap in CI so sandbox tests can run, and use Python 3.14 as the
  default for local uv commands and all CI jobs.
- Keep streaming answers pinned to the bottom when rendering falls behind
  incoming chunks, while preserving manual scrolling.

Release tag: `v0.1.19b1`. This is a prerelease and does not replace the latest
stable release. Install it using `/update edge`.

**Full changelog:** https://github.com/0v3rf3ar/Eirene/compare/v0.1.18...v0.1.19b1
