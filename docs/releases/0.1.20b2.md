# Eirene 0.1.20b2

This beta fixes prompt-navigation races and keeps UI icons monochrome on Windows,
Linux, and macOS.

- Update the selected prompt as soon as the transcript scrolls. Cancel queued
  bottom-follow callbacks when a prompt jump is requested, before its deferred
  scroll runs, and apply clicked prompt jumps immediately.
- Replace emoji-capable UI icons with ordinary text symbols. Manual mode uses
  `Ⅱ`, auto mode uses `↯`, and plan mode uses `≡`. Icons inherit the surrounding
  text color without requesting a platform's colored emoji font. User and model
  messages are unaffected.

Release tag: `v0.1.20b2`. This is a prerelease; stable users remain on `0.1.19`.
