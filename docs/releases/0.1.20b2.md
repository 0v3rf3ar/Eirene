# Eirene 0.1.20b2

This beta fixes prompt-navigation races and keeps UI icons monochrome on Windows,
Android, Linux, and macOS.

- Update the selected prompt as soon as the transcript scrolls. Cancel queued
  bottom-follow callbacks when a prompt jump is requested, before its deferred
  scroll runs, and apply clicked prompt jumps immediately.
- Replace emoji-capable UI icons with ordinary text symbols. Manual mode uses
  `Ⅱ`, auto mode uses `↯`, and plan mode uses `≡`. Icons inherit the surrounding
  text color without requesting a platform's colored emoji font. User and model
  messages are unaffected.
- Retain experimental ARM64 Termux packaging with an explicit Android API level
  for native Pydantic Core wheels. The package is built and smoke-tested in the
  official Termux container before publication when the optional job succeeds.

The previous Termux beta passed native import, CLI, diagnostics, shell, file-read,
and PTY UI checks in Android/Bionic userspace. Physical Android device testing
has not been performed. Native provider CLIs, third-party MCP servers, and Android
integration features may need further porting.

For the standard F-Droid/GitHub `com.termux` distribution on ARM64 with Python 3.14:

```sh
pkg update
apt install ./eirene-Termux-aarch64-0.1.20b2.deb
eirene --doctor
eirene
```

Arbitrary Termux commands require explicit approval. Plan mode supports fixed
file/search tools and blocks arbitrary commands because kernel command isolation
is unavailable. Scheduling and desktop binary self-updates are unsupported;
install a newer `.deb` to update.

Release tag: `v0.1.20b2`. This is a prerelease; stable users remain on `0.1.19`.
