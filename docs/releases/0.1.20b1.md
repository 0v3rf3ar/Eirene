# Eirene 0.1.20b1

This beta adds an experimental Android ARM64 package for Termux.

- Build an optional `eirene-Termux-aarch64-0.1.20b1.deb` in the official Termux
  Docker environment on a native ARM64 GitHub Actions runner.
- Use Termux Python 3.14 and packaged native dependencies. Build the locked
  Pydantic Core version for Android and vendor the remaining Python runtime
  dependencies without changing the user's Python packages.
- Test native imports, version/help, diagnostics, shell execution, file reads,
  and the terminal UI in Android/Bionic userspace before uploading the package.
- Discover Bash/sh through PATH and recognize Termux's package manager and paths.
- Require explicit approval for arbitrary Termux commands. Plan mode permits
  fixed file/search tools and blocks arbitrary commands because kernel command
  isolation is unavailable. Scheduling and desktop binary self-updates are not
  supported in this experimental package.

The Termux job is experimental and does not block desktop releases. A Termux
asset is included only if its build and smoke tests pass. Container testing is
not physical Android device validation. Android integration features, native
provider CLIs, and third-party MCP servers may need additional porting.

Install from Termux (F-Droid/GitHub com.termux distribution, ARM64):

```sh
pkg update
apt install ./eirene-Termux-aarch64-0.1.20b1.deb
eirene --doctor
eirene
```

This package uses the standard `/data/data/com.termux/files/usr` prefix and
requires Termux Python 3.14. Download a newer Termux `.deb` to update; `/update`
does not install desktop binaries on Android.

Release tag: `v0.1.20b1`. This is a prerelease; stable users remain on `0.1.19`.
