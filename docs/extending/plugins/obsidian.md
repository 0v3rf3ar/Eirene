# Obsidian

[Documentation](../../README.md) / [Plugin catalog](../plugin-catalog.md) / Obsidian

These skills teach Eirene to work with [Obsidian](https://obsidian.md) vault files.

## Install

```text
/plugins install obsidian
/plugins trust obsidian
```

Eirene ships this bundle, so installing needs no network. Open your vault as the workspace, or point Eirene at it, so the files are within reach.

## Commands

| Command | Purpose | Needs |
| --- | --- | --- |
| `/obsidian-markdown` | Obsidian Flavored Markdown: wikilinks, embeds, callouts and properties. | |
| `/obsidian-bases` | Create and edit `.base` files with views, filters and formulas. | |
| `/json-canvas` | Create and edit `.canvas` files. | |
| `/obsidian-cli` | Work with a running vault. | The Obsidian CLI |
| `/knap` | Render Markdown from templates and structured data. | The Knap CLI |
| `/defuddle` | Extract clean Markdown from web pages. | The Defuddle CLI |
