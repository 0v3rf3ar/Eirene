# Prompt suggestions

[Documentation](README.md) / Prompt suggestions

Prompt suggestions are optional follow-up drafts generated by the active model.
They are off by default. Enable them when you want help choosing the next request
after a response.

```text
/prompt-suggest on
/prompt-suggest off
```

`/prompt-suggest` without arguments opens the status and toggle panel. Ctrl+P
also toggles suggestions. The preference is saved for later sessions.

## Accept a draft

A suggestion appears as muted text when the composer is empty. Press Tab or Right
arrow to copy it into the composer, edit it if needed, and press Enter to send.
Typing your own text replaces the suggested draft. A suggestion does not run
itself or become part of the transcript until you send it.

Generation can finish after the main response. Open the suggestion panel to see
its current status or a failure. Toggling the feature resets its suggestion state.

## Requests and context

Suggestions make an additional model request using a bounded portion of the
recent request and reply. They use no tools and cannot edit files. They can consume
provider tokens or subscription allowance even when you do not send the draft.
Use the provider's usage controls if those extra requests matter to your budget.

For a one-off question without changing the main conversation, see
[side questions](side-questions.md).
