# Eirene's plugins

The plugins customized for Eirene, one folder each. `/plugins install NAME` copies the
one packaged with your Eirene; `/plugin update NAME` reads the newest from this folder
on the repository's `master` branch.

Each one builds on someone else's work, with our thanks:

| Plugin | Original | Author | License |
| --- | --- | --- | --- |
| `superpowers` | [obra/superpowers](https://github.com/obra/superpowers) | Jesse Vincent | MIT |
| `arena` | [Jakeschincariol/arena-skill](https://github.com/Jakeschincariol/arena-skill) | Jake Schincariol | MIT |
| `obsidian` | [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) | Steph Ango | MIT |
| `eirene-skills` (`frontend-design` only) | [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design) | Anthropic | Apache-2.0 |

The rest of `eirene-skills` was written for Eirene. See the [NOTICE](../../NOTICE) file
for what changed from each original.
